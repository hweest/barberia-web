# ✂️ Barbería Web

Sistema completo de gestión para barbería con:

- 📱 Reservas online
- 🖼️ Galería de imágenes
- 🔐 Panel de administración
- 📧 Recuperación de contraseña
- 💬 Integración con WhatsApp

## 🚀 Tecnologías

- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Base de datos**: MongoDB Atlas
- **Autenticación**: JWT
